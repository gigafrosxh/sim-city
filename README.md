# City-Sim

Ein modernes, SimCity-ähnliches Städtebauspiel als Webanwendung.

- [`frontend/`](frontend/) – Angular/TypeScript-Oberfläche mit isometrischer Stadtkarte.
  Läuft dank eingebauter Simulation auch ohne Backend.
- [`docs/api-contract.md`](docs/api-contract.md) – Schnittstelle zwischen Frontend und Backend
  (REST + WebSocket) inklusive Simulationsregeln.
